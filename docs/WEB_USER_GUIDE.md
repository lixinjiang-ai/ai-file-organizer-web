# AI File Organizer Web — User Guide / 使用说明

AI File Organizer Web is the international web version of AI File Organizer. It runs entirely in your browser.

## English

### File Organizer
1. Open **File Organizer** from the top menu.
2. Drag & drop files into the box, or click to select. Multiple files are supported.
3. Files are automatically grouped by type: Documents, Spreadsheets, Presentations, Images, Archives, Audio, Video, Code, Other.
4. Review the category preview.
5. Click **Organize & Download ZIP** to get a tidy archive with one folder per category.
6. Your original files are never modified.

### OCR
1. Open **OCR** from the top menu.
2. Upload an image (JPG/PNG/…).
3. Choose language (English / 中文), then click **Extract Text**.
4. Copy or download the recognized text as `.txt`.

### Privacy
All processing happens locally in your browser. Nothing is uploaded to a server, and no files are stored.

## 中文

### 文件整理
1. 在顶部菜单打开「文件整理」。
2. 把文件拖入方框，或点击选择，支持多文件。
3. 文件按类型自动归为：文档、表格、演示、图片、压缩包、音频、视频、代码、其他。
4. 查看分类预览。
5. 点击「整理并下载 ZIP」获取按类别分文件夹的压缩包。
6. 原始文件不会被修改。

### OCR
1. 在顶部菜单打开「OCR」。
2. 上传图片（JPG/PNG 等）。
3. 选择语言（English / 中文），点击「提取文字」。
4. 复制或下载识别结果为 `.txt`。

### 隐私
所有处理均在浏览器本地完成，文件不会上传或存储。

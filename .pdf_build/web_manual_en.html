1. Product Introduction

AI File Organizer — Web Edition is the international, browser-based version of AI File Organizer. It helps you sort messy files into tidy folders, and extract text from images with OCR — all running inside your browser.

Highlights:

  • No install. Open the web page and start immediately.
  • Free. No account, no payment.
  • Private by design. Files are processed locally on your device and never uploaded.
  • Two tools: File Organizer (sort into categories) and OCR (image → text).
Tip: The web edition is ideal for quick, one-off organizing on any computer or phone. For offline, always-available use on a Mac, see the companion macOS DMG.

2. How to Access

  1. Open a modern browser (Chrome, Edge, Safari, or Firefox — recent versions).
  2. Visit: https://lixinjiang-ai.github.io/ai-file-organizer-web/
  3. That's it — no download, no sign-up. The page works on desktop and mobile.

Language: the interface defaults to English; use the 中文 / EN button in the top menu to switch to Chinese.

3. Getting Started

  • From the top menu, choose File Organizer or OCR.
  • Your files are processed on this device only. You can close the tab at any time.

4. Using the File Organizer

  1. Open File Organizer from the top menu.
  2. Add files: drag & drop files into the box, or click to select. Multiple files are supported.
  3. Auto-group: files are grouped by type — Documents, Spreadsheets, Presentations, Images, Archives, Audio, Video, Code, Other.
  4. Review the category preview.
  5. Click Organize & Download ZIP to get a tidy archive with one folder per category.
  6. Your original files are never modified; the ZIP is a new download.

5. Using OCR

  1. Open OCR from the top menu.
  2. Upload an image (JPG / PNG / …).
  3. Choose a language (English / 中文), then click Extract Text.
  4. Copy the recognized text, or download it as a .txt file.
First-time note: OCR downloads a small language model (eng or chi_sim) on first use, so an internet connection is needed the first time. After that it runs faster. Recognition happens locally in your browser.

7. Frequently Asked Questions (FAQ)

Q1: Is my data safe?

Yes. All processing runs in your browser; nothing is uploaded to a server and no files are stored.

Q2: Do I need to install anything?

No. Just open the URL. There is no account to create.

Q3: Is it free?

Yes — completely free to use.

Q4: OCR is slow or not working?

The first recognition downloads the language model (a few MB), so it needs internet on first use. Large images take longer. Use a modern browser.

Q5: Can I organize very large files?

Processing is client-side; very large batches may be slower or limited by your device memory. For huge jobs, split into smaller batches.

Q6: Does it work on my phone?

Yes — the interface is responsive and works on phones and tablets.

8. Notes & Tips

  • Use a recent version of Chrome, Edge, Safari, or Firefox.
  • OCR needs internet the first time to fetch its language model.
  • Your originals are never changed — the app only produces a new ZIP / text.
  • No account, no cloud storage, no usage tracking.

9. Privacy & File Handling

  • Local processing: file organizing and OCR run entirely in your browser. Files are not uploaded.
  • No storage: we do not store your files or results on any server.
  • No telemetry: the app does not track usage or send analytics.
  • Open source: the code is public so you can verify the above claims.

一、产品简介

AI File Organizer — Web 国际版 是 AI 文件整理助手的浏览器版本。它帮你把杂乱文件快速归类，并能从图片中提取文字（OCR）——全部在浏览器内运行。

核心特点：

  • 免安装：打开网页即可使用。
  • 免费：无需账号、无需付费。
  • 隐私优先：文件在本机处理，不会上传。
  • 两个工具：文件整理（按类归类）+ OCR（图片转文字）。
提示：Web 版适合在任何电脑或手机上快速整理文件。如需 Mac 上离线、常驻使用，请看配套的 macOS DMG。

二、如何访问

  1. 打开现代浏览器（Chrome / Edge / Safari / Firefox 的新版本）。
  2. 访问：https://lixinjiang-ai.github.io/ai-file-organizer-web/
  3. 无需下载、无需注册，桌面与手机均可使用。

语言：界面默认英文，点击顶部菜单的「中文 / EN」按钮可切换为中文。

三、开始使用

  • 在顶部菜单选择「文件整理」或「OCR」。
  • 文件仅在本设备处理，可随时关闭页面。

四、使用文件整理

  1. 在顶部菜单打开「文件整理」。
  2. 添加文件：把文件拖入方框，或点击选择，支持多文件。
  3. 自动分组：文件按类型归为：文档、表格、演示、图片、压缩包、音频、视频、代码、其他。
  4. 查看分类预览。
  5. 点击「整理并下载 ZIP」，获得按类别分文件夹的压缩包。
  6. 原始文件不会被修改；ZIP 是全新下载。

五、使用 OCR 文字识别

  1. 在顶部菜单打开「OCR」。
  2. 上传图片（JPG / PNG 等）。
  3. 选择语言（English / 中文），点击「提取文字」。
  4. 复制识别结果，或下载为 .txt 文件。
首次使用提示：OCR 首次会下载一个小语言模型（eng 或 chi_sim），因此首次需要联网；之后更快。识别过程在浏览器本地完成。

六、支持的文件类型

文件整理按扩展名归入以下类别：

类别常见扩展名
文档.pdf .docx .txt .md …
表格.xlsx .csv .xls …
演示.pptx .ppt …
图片.jpg .png .gif .webp …
压缩包.zip .rar .7z …
音频.mp3 .wav .flac …
视频.mp4 .mov .avi …
代码.js .py .html …
其他未匹配到的文件

OCR 支持常见图片格式（JPG / PNG / GIF / WebP）。

七、常见问题（FAQ）

Q1：我的数据安全吗？

安全。全部处理在浏览器内进行，文件不上传、不存储。

Q2：需要安装什么吗？

不需要。打开网址即可，无需注册账号。

Q3：收费吗？

完全免费。

Q4：OCR 很慢或识别不出？

首次识别会下载语言模型（几 MB），需联网；大图耗时更久。请使用现代浏览器。

Q5：能处理超大文件吗？

处理在本地进行，超大批量可能较慢或受设备内存限制；建议分批处理。

Q6：手机能用吗？

可以，界面自适应，支持手机与平板。

八、注意事项

  • 请使用较新的 Chrome / Edge / Safari / Firefox。
  • OCR 首次需联网以下载语言模型。
  • 原始文件永不被改动，应用只生成新的 ZIP / 文本。
  • 无账号、无云存储、无使用追踪。

九、隐私与文件处理说明

  • 本地处理：文件整理与 OCR 均在浏览器内完成，文件不上传。
  • 不存储：我们不会在服务器保存你的文件或结果。
  • 无遥测：应用不追踪使用、不发送分析数据。
  • 开源：代码公开，你可自行验证上述声明。

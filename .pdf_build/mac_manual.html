一、产品简介

AI 文件整理助手是一款帮助你把杂乱文件快速归类、转换与识别的桌面工具。Mac 版专为 Apple Silicon 芯片的 macOS 设备打造，可离线运行，适合日常办公、资料归档与文档处理。

核心能力：

  • 文件整理：把混合的文件按类型自动分入对应文件夹（文档 / 图片 / 音频 / 视频等）。
  • Word → PDF 转换：借助本机已安装的 Microsoft Word 或 LibreOffice 完成文档转换。
  • OCR 文字识别：从图片中提取文字，可复制到剪贴板。
  • AI 智能分类（可选）：配置 API Key 后，可按文件内容语义做更精细的分类。
提示：除「AI 智能分类」与首次启动验证需要网络外，文件整理、OCR、Word→PDF 均可完全在本机完成，原始文件不会被上传。

三、安装方法（从 DMG 安装）

3.1 标准安装（推荐）

  1. 找到下载的安装包 AI文件整理助手_Mac_arm64.dmg，双击挂载磁盘映像。
  2. 在弹出的窗口中，将 AI文件整理助手.app 拖拽到「应用程序（Applications）」文件夹，等待复制完成。
  3. 右键点击桌面上的 DMG 图标，选择「推出」以卸载磁盘映像。

3.2 首次启动

由于本应用未经过 Apple 公证（Gatekeeper），首次启动可能遇到安全提示。请按以下步骤允许运行：

  1. 打开「系统设置」→「隐私与安全性」。
  2. 在「安全性」区域，点击「仍要打开」。
  3. 在弹出的对话框中点击「打开」。
说明：这是 macOS 对未公证应用的正常保护机制，并非应用损坏。之后的启动将不再提示。

四、使用步骤

4.1 文件整理

  1. 添加文件：将需要整理的文件拖入应用窗口（支持批量、支持多种类型）。
  2. 自动分类：应用按文件类型自动分组，可在界面中查看分类预览。
  3. 开始整理：点击整理，文件会被归入对应类型的文件夹；原始文件不会被覆盖或修改。

4.2 Word → PDF 转换

  1. 选择需要转换的 .docx 文件。
  2. 点击「转换为 PDF」。
  3. 等待转换完成，PDF 将保存在原文件同一目录。

4.3 OCR 文字识别

  1. 选择图片文件（.jpg / .png 等）。
  2. 点击「OCR 识别」，应用将提取图片中的文字。
  3. 结果可一键复制到剪贴板，或保存为文本。

4.4 AI 智能分类（可选）

在「设置」中配置 API Key 后开启 AI 分类，应用会分析文件内容语义进行更精确的分类。详见第七节。

提示：Word→PDF 依赖本机组件（见下表）；OCR 支持常见图片格式。

Word → PDF 转换组件支持

软件版本要求支持状态
Microsoft Word for Mac2019 / 2021 / 2024 / 365✅ 优先支持
LibreOffice7.0 及以上✅ 降级支持
WPS Office任意版本⚠️ 不支持自动转换

应用会按以下优先级查找转换组件：① Microsoft Word for Mac（AppleScript 自动化）→ ② LibreOffice（headless）→ 若均未安装则给出友好提示，其他功能仍正常。

六、AI Key 配置

6.1 获取 API Key

  1. 访问 https://platform.openai.com，注册并登录账号。
  2. 在后台创建 API Key 并复制（格式形如 sk-xxxxxxxx）。

6.2 配置方法

  1. 启动应用，在主界面点击「设置」。
  2. 在「AI 配置」区域粘贴 API Key，点击「保存」。

6.3 注意事项

  • API Key 仅存储在本地，不会上传到任何服务器。
  • 建议定期更换 Key；如遇调用限制，请检查账户余额。

七、常见问题（FAQ）

Q1：应用无法启动？

① 检查系统版本是否满足 macOS 12.0+；② 确认已授予「完全磁盘访问权限」；③ 尝试重新安装。

Q2：拖拽功能不工作？

① 确认使用支持拖拽的窗口；② 检查是否启用「辅助功能」权限；③ 重启应用后重试。

Q3：Word → PDF 转换失败？

① 确认已安装 Microsoft Word 或 LibreOffice；② 检查 Word 是否支持 AppleScript；③ 手动打开文件确认未损坏。

Q4：AI 分类功能报错？

① 检查 API Key 是否有效；② 确认网络连接正常；③ 查看 OpenAI 官方状态页面。

Q5：应用运行缓慢？

① 关闭其他占用资源的应用；② 减少单次处理文件数量；③ 确保磁盘空间充足。

八、注意事项

  • 本应用未经过 Apple 公证，首次启动需按第三节允许运行。
  • 文件整理不会改变或覆盖你的原始文件；整理结果输出到新位置。
  • AI 功能依赖你自己的 API Key 与网络，调用可能产生费用，由对应服务商收取。
  • 使用 WPS Office 时，Word→PDF 自动转换不可用，建议安装 Microsoft Word 或 LibreOffice。
重要声明：本版本已完成 macOS ARM64 云端构建，但尚建议在真实 Mac 设备上全面测试后再用于生产环境；如发现任何问题，请及时反馈至 GitHub Issues。

九、隐私与文件处理说明

  • 文件本地处理：文件整理、OCR、Word→PDF 均在你的 Mac 本机完成，原始文件不会被上传到任何服务器。
  • API Key 本地保存：AI Key 仅存储于本机，不会外传。
  • 网络使用范围：仅「首次启动验证」与「AI 智能分类」需要联网；其余功能可离线使用。
  • 我们不收集数据：本应用不内置遥测、不上传你的文件或内容。

十、卸载方法

10.1 标准卸载

  1. 打开「访达」→「应用程序」。
  2. 找到「AI 文件整理助手」，右键「移到废纸篓」，并清空废纸篓。

10.2 清理配置数据（可选）

# 应用配置
rm -rf ~/Library/Application\ Support/AI文件整理助手

# 缓存文件
rm -rf ~/Library/Caches/com.aiorganizer.fileorganizer

# 偏好设置
rm -rf ~/Library/Preferences/com.aiorganizer.fileorganizer.plist
